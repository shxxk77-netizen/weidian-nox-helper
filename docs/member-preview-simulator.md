# 영상형 VIP 미리보기 시뮬레이터

이 프로토타입은 데스크톱 앱 또는 Chrome 패널에서 선택한 VIP 등급을 Weidian 회원 화면에 로컬로 재현합니다.

## 동작

- `apply-member-preview`와 패널의 로컬 적용 버튼을 감지합니다.
- 상점별 선택값을 `chrome.storage.local`에 저장해 전체 새로고침 뒤에도 다시 적용합니다.
- 화면에 노출된 기존 `折` 값을 기준 할인율로 감지합니다.
- 목표 등급 할인율과 기준 할인율의 비율로 회원 혜택 가격 표시를 다시 계산합니다.
- VIP 등급별 카드 배경, 전경색, 강조색을 적용합니다.
- DOM이 다시 렌더링되거나 SPA 경로가 바뀌어도 회원 화면에서 상태를 재적용합니다.
- 로컬 원복 명령을 실행하면 저장값과 변경된 화면 표시를 제거합니다.

## 기본 프로필

| 등급 | 할인율 표시 | 배율 |
| --- | ---: | ---: |
| VIP1 | 10折 | 1.00 |
| VIP2 | 9.8折 | 0.98 |
| VIP3 | 9.5折 | 0.95 |
| VIP4 | 8.9折 | 0.89 |
| VIP5 | 8.6折 | 0.86 |
| VIP6 | 8.2折 | 0.82 |

예를 들어 현재 화면이 VIP3 `9.5折`, 가격이 `¥150.10`인 경우:

```text
VIP4: 150.10 × 0.89 ÷ 0.95 = 140.62
VIP5: 150.10 × 0.86 ÷ 0.95 = 135.88
```

## 실행 범위

시뮬레이터는 회원등급, 회원카드, 회원혜택 화면에서만 동작합니다. 다음 경로에서는 변경 내용을 복원하고 시뮬레이션 표시를 중단합니다.

- 주문 확인
- 주문 생성
- cashier
- `pay-h5`
- 결제 화면

네트워크 요청, 로그인 세션, 주문 payload, 결제 토큰, 서버 회원 상태는 변경하지 않습니다. 화면 우측 하단의 `LOCAL SIM` 배지가 활성 상태를 표시합니다.

## 빌드

```bash
npm run build:source
```

빌드 결과로 `chrome-extension/member-simulator.js`가 생성되며 `manifest.json`에서 `content.js` 다음에 로드됩니다.
